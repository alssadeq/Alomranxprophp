# موقع العمران الذهبية للمقاولات العامة — نسخة PHP

نسخة من الموقع تعمل على استضافة **Hostinger Premium** (PHP فقط، بدون Node.js)، بنفس الشكل والمحتوى تماماً.

النسخة تقرأ وتكتب **نفس ملفات `data/`** التي تستخدمها نسخة Node.js. يمكن نقل مجلد `data` بين النسختين في أي وقت دون تحويل.

## ما يعمل

الموقع كاملاً كما في نسخة Node.js:

| القسم | التفاصيل |
|---|---|
| الصفحات العامة | الرئيسية، من نحن، أعمالنا، صفحة المشروع، منهجيتنا، الخصوصية، طلب المشروع. المخرجات مطابقة حرفياً لنسخة Node |
| النماذج | التواصل، وطلب المشروع مع المرفقات والتقرير القابل للطباعة، ورابط تقييم العميل |
| المحادثة | الردود الجاهزة، والخدمات، ووكلاء الذكاء الاصطناعي (Gemini وChatGPT وClaude)، والتحويل لموظف، والرد من لوحة التحكم |
| لوحة التحكم | كل الأقسام: الأعمال، والرسائل، والمحادثات، وطلبات المشاريع، والعملاء، والتقييمات، والهوية والمظهر، وأقسام الصفحات، ووسائل التواصل، وسجل النشاط، والإشعارات، والحسابات والصلاحيات |
| البريد | بريد الشركة من لوحة التحكم (SMTP)، وإشعارات الطلبات، والتقرير الدوري، والتذكيرات، واستعادة كلمة المرور |
| مركز المطوّر | الحالة، والأمان، والأخطاء، وقاعدة البيانات، والسجل، ووضع الصيانة، والنسخ الاحتياطي والتصدير، ووكلاء الذكاء الاصطناعي |

### التوافق مع بيانات نسخة Node

- الحسابات وكلمات المرور تعمل كما هي، لأن التشفير بنفس الصيغة (scrypt).
- كلمة مرور بريد الشركة المحفوظة تعمل كما هي، لأن مفتاحها داخل `data/.mail-key`.
- مفاتيح الذكاء الاصطناعي تعمل إذا وضعت نفس `SESSION_SECRET` في `app/config.php`، وإلا فأعد إدخالها من مركز المطوّر.
- الجلسات لا تنتقل، فيسجّل الجميع الدخول مرة واحدة.

### اختلافات عن نسخة Node

- **التحديث الآلي** من مركز المطوّر غير متاح. التحديث يتم برفع ملف النسخة الجديدة في مدير الملفات.
- **مراقبة الأداء اللحظية** غير متاحة على الاستضافة المشتركة.
- **المهام الدورية** (التقرير والتذكير) تُفحص مع زيارات الموقع، كل 5 دقائق على الأكثر، بدل مؤقت دائم.

## هيكل الملفات

```
index.php        نقطة الدخول الوحيدة
.htaccess        الروابط النظيفة وحماية المجلدات الداخلية
.user.ini        حجم الرفع وإعدادات PHP
app/             الكود (محمي من المتصفح)
backups/         النسخ الاحتياطية من مركز المطوّر (محمية)
data/            البيانات — تُنشأ تلقائياً، ومحمية من المتصفح
css/ js/ fonts/ images/ *.html   واجهة الموقع (نفس ملفات public في نسخة Node)
```

- PHP 8.1 أو أحدث (يُنصح بـ 8.2 أو 8.3).
