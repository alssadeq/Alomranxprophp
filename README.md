# موقع العمران الذهبية للمقاولات العامة — نسخة PHP

نسخة من الموقع تعمل على استضافة **Hostinger Premium** (PHP فقط، بدون Node.js)، بنفس الشكل والمحتوى تماماً.

النسخة تقرأ وتكتب **نفس ملفات `data/`** التي تستخدمها نسخة Node.js. يمكن نقل مجلد `data` بين النسختين في أي وقت دون تحويل.

## ما يعمل في هذه المرحلة (المرحلة الأولى)

| الميزة | الحالة |
|---|---|
| كل صفحات الموقع: الرئيسية، من نحن، أعمالنا، صفحة المشروع، منهجيتنا، الخصوصية | ✅ نفس المخرجات حرفياً |
| الإعدادات والصور والشعار والخطوط والأقسام، وزر الدخول (إظهار/إخفاء) | ✅ |
| بطاقة المشاركة (واتساب وتويتر...) | ✅ |
| نموذج التواصل | ✅ يُحفظ في `messages.json` مع إشعار بالبريد |
| نموذج طلب المشروع (البريف) مع المرفقات والتقرير القابل للطباعة | ✅ |
| رابط تقييم العميل `/review/...` | ✅ |
| أيقونات وسائل التواصل وعدّاد النقرات | ✅ |
| المحادثة: الردود الجاهزة وقائمة الخدمات وطلب الخدمة وواتساب والاتصال والمرفقات | ✅ |
| التحويل إلى موظف | ✅ يصل للفريق بالبريد، ويظهر للعميل زر واتساب |
| قاعدة العملاء | ✅ تُسجَّل تلقائياً |
| **لوحة التحكم وتسجيل الدخول** | ⏳ المرحلة الثانية |
| الرد المباشر على المحادثات والذكاء الاصطناعي | ⏳ المرحلة الثانية |

## هيكل الملفات

```
index.php        نقطة الدخول الوحيدة
.htaccess        الروابط النظيفة وحماية المجلدات الداخلية
.user.ini        حجم الرفع وإعدادات PHP
app/             الكود (محمي من المتصفح)
data/            البيانات — تُنشأ تلقائياً، ومحمية من المتصفح
css/ js/ fonts/ images/ *.html   واجهة الموقع (نفس ملفات public في نسخة Node)
```

## المتطلبات

- PHP 8.1 أو أحدث (يُنصح بـ 8.2 أو 8.3).
- Apache أو LiteSpeed مع `mod_rewrite`. هذا متوفر افتراضياً في Hostinger.
