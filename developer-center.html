نقل الموقع إلى استضافة أخرى

  1. أنشئ نسخة من نوع «تصدير الموقع لاستضافة أخرى» ونزّلها.
  2. على الاستضافة الجديدة أنشئ تطبيق Node.js (الإصدار 20 أو أحدث)، وملف التشغيل server.js، وأمر التشغيل npm start.
  3. ارفع ملف ZIP كما هو أو فك ضغطه في مجلد التطبيق، ثم ثبّت الحزم بـ npm install --omit=dev.
  4. أدخل متغيرات البيئة: NODE_ENV، SESSION_SECRET، BOOTSTRAP_TOKEN، APP_BASE_URL وإعدادات البريد SMTP_*.
  5. شغّل التطبيق وسجّل الدخول بحساباتك الحالية، ثم وجّه النطاق إلى الاستضافة الجديدة.

التفاصيل الكاملة داخل الحزمة في ملف MIGRATION-README.md.

ارفع ملف الموقع ZIP كما يصلك (مثل Alomranxprophp-2.2.0.zip). رقم الإصدار يُقرأ من الملف تلقائياً، ولا يُلمس مجلد data ولا ملف الإعدادات.

ZIP / حتى 40MB

اختياري: يُستخدم رقم الإصدار الموجود داخل ملف التحديث.

الحماية: تُرفض المسارات غير الآمنة والرموز الرمزية، ولا يُثبَّت أي ملف داخل data أو backups. قبل التثبيت تُحفظ نسخة (Snapshot) من الملفات المستبدلة للرجوع إليها بزر Rollback.

وكلاء خدمة العملاء في محادثة الموقع. مفاتيح API تُشفَّر على الخادم ولا تُرسل إلى المتصفح بعد الحفظ، وكل الاستدعاءات تتم من الخادم. عند إيقاف كل الوكلاء تعمل المحادثة بالردود التقليدية.
